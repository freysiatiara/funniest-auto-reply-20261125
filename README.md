`main.py` (stdlib only) writes one deadpan out-of-office auto-reply line to
`/output/entry.txt`:

> My human approved my day off. I've rescheduled your urgency to a time when I care.

Run it with `python3 main.py`. See `CANDIDATES.md` for the candidate panel
and why this line was chosen.
